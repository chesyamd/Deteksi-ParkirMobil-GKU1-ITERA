# Dokumen Tugas Besar

Folder ini berisi kerangka dokumen. Semua bagian bertanda `TODO` **wajib
dilengkapi tim** setelah data asli dan hasil evaluasi tersedia.

| Berkas | Isi |
|---|---|
| `proposal.md` | kerangka proposal |
| `laporan_outline.md` | outline laporan akhir 5 bab |
| `template_hasil.md` | template tabel hasil & analisis |
| `protokol_pengambilan_foto.md` | protokol pengambilan data primer |
| `bacaan.md` | daftar bacaan awal + rujukan klasik |
| `progres_mingguan.md` | template catatan progres |
| `naskah_video.md` | naskah video demo |
| `todo_manusia.md` | daftar pekerjaan yang butuh manusia |

## Aturan penting

- **Jangan mengarang angka.** Semua angka di laporan harus berasal dari
  `results.csv`/`results.md` yang dihasilkan dari data asli.
- Hasil dari `sandbox/` (data sintetis) hanya untuk smoke test dan **tidak
  boleh** dimasukkan sebagai hasil penelitian.
- Sebutkan kondisi pengambilan foto (waktu, cuaca, sudut, handheld) dan
  keterbatasan.
